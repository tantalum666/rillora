This folder is the active Rillora brand source. The Owner selected the original03 board. The R monogram, book, leafy tree and line-tree studies remain historical alternatives and must not replace it. The untouched [selected board](../rillora-identity-03-legacy-imprint-20260919/identity-board.png) and its original source folder retain their creation-time notes; this file and [brand.json](../../../config/brand.json) record the later adoption.

## Use

- `symbol-forest.svg`, `symbol-black.svg`, `symbol-white.svg`: standard symbol.
- `symbol-micro.svg`: restricted to tiny browser favicons; never substitute it in an app/page header.
- `wordmark-forest.svg`: outlined Source Serif4 SemiBold wordmark. `wordmark-source.svg` is retained source artwork.
- `lockup-primary.svg`: forest symbol and wordmark on light surfaces.
- `lockup-white.svg`: original white reverse. `lockup-reversed.svg` is a paper-colour-only derivative for existing dark UI.
- `lockup-small-reversed.svg`: historical simplified experiment; deprecated for product use after the Owner reported a different mobile Logo. Every header uses `lockup-reversed.svg`, scaled proportionally.
- `app-icon-dark.png`: selected1024×1024 opaqueRGB icon for the main iOS target. Light/bronze files are secondary variants, not automatic user-selectable icons. Let iOS apply its outer mask.
- `favicon.svg`, `favicon-32.png`: small website icons. Additional source SVG/transparent PNG exports retain the selected03 geometry.
- `identity-board.png` is the selected presentation reference. `manifest.json` records file hashes. The adjacent `rillora-approved-brand-20260920.zip` is the current distribution copy; the September19 ZIP is a dated historical package.

Keep the aspect ratio, clear space and original contours. Do not add a shadow, bevel, gradient, animated morph or additional tree leaves. The brand palette is forest`#23473D`, paper`#F5F1E8`, bronze`#BD9473`; it does not replace the existing Graphite/Prepared Folio interface palette.

## Font licences

The outlined wordmark uses Source Serif4 SemiBold, tracking−1.4%; it needs no locally installed font for rendering. Source Serif4 and Inter allow commercial use underOFL1.1. Full Adobe/Google Fonts/Inter licence files and exact sources are included. Keep these with any bundled font software. Logo artwork and application code do not inheritOFL.
