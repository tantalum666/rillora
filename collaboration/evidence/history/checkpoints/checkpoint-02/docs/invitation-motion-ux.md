- Person -> Access -> Link are one understandable sequence. Existing name and
  optional relationship save continues to the actual per-item sharing screen.

  Crypto locators and Notes remain Details-only. Never disclose stays unavailable.

## Motion and page hierarchy

- Overview: folio entry/press response, live matter count, one add action and a
  direct outgoing relationship action. Populated pages retain actual matter rows.
- Profile: people before subscription tools; incoming separate from outgoing.
- Person/access/link steps visibly advance; permission selection expands with a
  bounded transition and only confirmed server writes show saved feedback.
- Pending is a dashed connection, accepted a solid connection/check, unavailable
  explicit. Animation never implies identity, delivery, legal authority or release.
- Matter list, shared item detail and related task surfaces use the same restrained
  entry/selection/press language; no paragraph or card inventory added for density.
- Reduce Motion removes transforms and repeated motion. Content is immediately
  readable, targets >=44pt, Dynamic Type reflows and drafts survive cancellation.
