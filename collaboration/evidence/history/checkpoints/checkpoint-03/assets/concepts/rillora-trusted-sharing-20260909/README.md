# Rillora trusted-sharing interaction reference

Generated 2026-09-09 with the built-in ImageGen tool for the Owner's A/B/C flow.
[Reference board](interaction-reference.png) uses Rillora graphite, limestone,
sage and clay with controls rather than explanatory paragraphs.

The design prompt specified four screens: People; per-item Name/Directions/Details
selection; email-bound link/QR sharing; recipient account acceptance with a separate
after-acceptance result. All visible examples are synthetic. The generated QR
pattern is a concept only and is never used as a real invitation code.

Implementation retains the existing three native bottom tabs rather than the
board's extra tabs. Actual QR codes are generated by Core Image on iOS and the
local `qrcode` library on Web. Receiving screens show no matter information before
acceptance. Actual runtime and flow evidence are in the
[QA report](../../../output/qa/rillora-trusted-sharing-20260909/README.md).
