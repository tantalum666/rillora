01 · Web · Desktop

Secondary action alignment

Same My plan state at 1440 × 1000.

Root cause: full-width secondary buttons were not a flex alignment context. Repair: shared inline-flex, centered content, 8 px gap and non-shrinking SVGs. Measured icon center delta is now 0 px.

02 · Web · Drawer

Safety icon keeps its geometry

Same role-policy drawer at 1440 × 1000.

Root cause: the flex row allowed a 19 px SVG to shrink beside long copy. Repair: icon-bearing controls use flex: 0 0 auto. The safety icon remains 19 × 19 px.

03 · Web · Responsive

Compact rail and mobile reachability

Same Settings state at 900 px and 390 px.

Root cause: the compact CSS rule collapsed the active Settings icon, then removed the entire sidebar below 760 px without a replacement. Repair: text-only collapse at 900 px; a fixed seven-destination mobile bar at 390 px with 44 × 48 px targets.

04 · iOS · Rows

One optical icon column

Same Account preparation and security sections on iPhone 17e.

Root cause: each SF Symbol used its natural advance width, moving text starts from row to row. Repair: one reusable LabelStyle gives repeated rows a centered 28 pt icon column while preserving Dynamic Type.

05 · iOS · Navigation

Scrolled content stays below the title

Same Role disclosure screen, scrolled, on iPhone 17e.

Root cause: iOS 26’s translucent navigation layer let the first label remain legible beneath the title. Repair: one global opaque UINavigationBarAppearance for standard, scroll-edge, compact and compact-scroll-edge states.

Repair contract

Keep future alignment fixes structural

Shared source first

Repair icon slots, flex behavior, label styles and bar appearance at the component or theme layer.

No page nudges

Do not introduce per-screen offsets, transform hacks or one-icon padding exceptions.

Evidence boundaries

Browser geometry and Simulator screenshots prove these rendered states only; they do not prove physical-device or VoiceOver completion.
