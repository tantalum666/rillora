## Vector and type work

The R was reconstructed through explicit Bézier coordinates in [the builder](../../../tools/logo/build-rillora-identity-20260919.cjs), without automatic bitmap tracing. A separate micro contour opens the neck and blunts the tip at 16/24px. The Source Serif 4 SemiBold wordmark is a licensed type treatment, exported as outlines from Figma; the native text reference remains editable. Its OFL is included with the package. No custom-font authorship is claimed.

Palette: pine #183B31, paper #F5F1E8, sage #CBDDAF. The package includes symbol/wordmark/combination SVGs and PNGs, black/reverse artwork, actual-size proofs, favicon and three opaque RGB 1024px icon masters. No flattening of the generated bitmap is presented as editable vector work.

The first Figma SVG import did not honor inherited currentColor on the wordmark. The source now writes explicit fills and the final Figma screenshot matches the palette. A tight lockup viewBox was expanded, symbol/type centers aligned and App icon scale corrected. The provisional made-up slogan was removed; the board contains design labels only. A local fontTools check found it unavailable; no package was installed because Figma provided a native outlined export.
