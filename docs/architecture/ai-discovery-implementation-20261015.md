## 官网候选

- 10 个公开页面各生成英文和简体中文 HTML，共20页。新增整理清单、与密码管理器分工两篇双语文章和资料索引；原先登录后平台指南仍保持认证边界。
- `/en/…` 与 `/zh-CN/…` 固定语言，正文、标题、描述、canonical、hreflang、分享元数据及结构化资料一致；旧地址与语言参数保持兼容。数据仅描述可见的品牌和页面，不编造评分、认证或法律效力。
- `robots.txt` 和20地址的 `sitemap.xml` 进入实际公开路由及完整文件指纹。基础设施上传校验只接受完整的20页矩阵及准确的 Rillora 规范地址，仍拒绝私有路径、遗漏资源和篡改字节。
- 首屏与正文无需 JavaScript 可读；FAQ 使用原生 details，交互页面提前加载后再 hydrate。静态渲染拒绝执行脚本／内联样式，未放宽现有 CSP。保留纸色／墨绿主题、既有导航和动效交互。
- 当前线上 www 仍是旧部署。没有向搜索站长平台提交、取得索引回执或测出 AI 推荐／引用增长；公开文章在本地候选中，不伪称已经发布。

## 最小 MCP 与选择授权

实现位于 `apps/api/src/mcp/`，使用官方 TypeScript SDK，支持已测试的 legacy 与2026-07-28协议。只提供两个工具：

| 工具 | 允许返回 | 明确不做 |
| --- | --- | --- |
| `list_selected_matters` | 授权事项的ID、名称、类别和记录状态 | 整份地图、备注、账号提示、金额、联系人、密码、密钥 |
| `get_preparation_gaps` | 选定事项适用的通用字段缺项名称 | 字段具体内容、分类完整性、合法权限或接收人准备度的保证 |

不提供写入、支付／退款、分享、删除、导出、身后释放、任意 SQL／URL 或模型调用。工具说明明确一般数字遗产咨询不需要读取私人事项。

下一版 Web 账号页可选择 AI 应用、最多20项事项、可选缺项检查，单独明确同意第三方处理后保存。默认未勾选；替换范围再次确认并通过精确版本条件原子替换旧授权。界面说明7天有效期、更新可读、撤销只能阻止后续读取，不能删除外部 AI 已经收到的副本；提供对应提供方隐私链接。

授权固定事项和字段，普通编辑后可继续复核。设为不披露或归档时，数据库触发器永久移除相关事项授权；改回原状态不会复活。撤销、到期、同意版本变化或恢复数据库后，新请求被拒绝。已在执行中的读取不能撤回，所有恢复路径要求重新明确授权。

OAuth 使用独立资源 audience、RS256签名、限定 issuer／client／scope、最多1小时 access token；拒绝M2M、原有Web／iOS客户端和第一方 Cookie／opaque token。新选择授权只接受之后签发的令牌。数据库继续使用原签名事务、强制RLS和账号状态／法律记录核对；未返回用户选择范围以外的信息。网络密钥服务故障不会被误报为用户登录过期。

新增0104—0105迁移与恢复日志 `ai_connection` 类型。日志仅记录撤销恢复语义，恢复后全部 AI 授权失效。全量回归发现0104包装日志函数时遗漏独立删除worker的原执行权限，0105补回该权限并撤销旧格式入口；删除／恢复25项聚焦及560项全量API随后通过。没有重写已执行迁移、放宽RLS或改动真实数据库。

## 平台接入材料与开关

[接入包](../../integrations/ai/README.md)及[生成器](../../tools/mcp/client-packages.mjs)提供 OpenAI portable plugin／MCP、Codex、Claude Code、Cursor、Gemini CLI 五套配置。只写入新的输出目录，不安装客户端、不覆盖全局配置、不生成或存放秘密。示例明确使用保留域名，不能当作真实连接地址。

Claude、Gemini Apps、Perplexity、Grok、Microsoft365、Qwen／Kimi与其他消费AI继续按各自地区／账户／入口核对，复用相同服务和权限模型；不能由同品牌CLI推导消费版已兼容。提供方回调、真实OAuth、目录批准和用户发现分别验收。本轮未取得任何真实平台连接或目录上架结果。

`ALLOW_MCP_INTEGRATION` 与 `VITE_RILLORA_AI_CONNECTIONS` 默认关闭。关闭或仅审核运行模式禁止挂载MCP；遗漏配置不能隐式开放。下一版部署次序固定为兼容broker → 0104—0105 → API／Web保持关闭 → 独立Auth0资源和平台客户端 → 隔离环境OAuth验收 → 各平台目录／发布。细节见接入包，不能回滚到不识别新授权日志的旧恢复处理器。

OpenAI等平台配置依据本轮已读取官方正文；公开JSON Schema地址额外下载因网络失败，没有冒称通过官方schema在线校验。本地配置生成、拒绝秘密／未知字段／错误域名／重复客户端及拒绝覆盖通过，不等于平台已接收。
