## 写作口径

- 统一使用“你”；标题与按钮优先省略不必要的人称。语气平实、有帮助，不渲染身故焦虑，不写空泛承诺。
- 先说用户要做什么、会发生什么。普通任务不用“响应”“会话”“包含名额”等内部术语；只有加密详情、测试工具等需要判断技术边界的地方保留必要说明。
- 同一概念在Web和原生iOS中使用同一中文；同一英文词在不同上下文可以有不同中文。联系人用“姓名”，事项用“名称”。
- 按钮表明动作，状态表明实际结果。创建邀请链接不是邮件已送达；停止在线共享不是收回已下载副本；账号删除不是取消付款平台的订阅。
- 不因文案改短而省略Notes是否可见、明文风险、恢复密钥不可找回、实际共享与法律权限分离等事实。
- 确认、取消、重试和重新登录必须说明当前结果；不暗示取消登录会丢草稿或认证完成后自动提交敏感操作。
- 完整句子使用中文句号；简短标签不强加句号。变量、数量、日期、币种和用户原文保持原义，不把用户内容当翻译键。

## 统一术语

| 概念 | 当前中文 | 用法与边界 |
| --- | --- | --- |
| Matter / Matter map | 事项 / 事项地图 | 不再混用“事务地图”“资料图谱”；不表示资产所有权登记 |
| Account | 账号；金融语境按需保留“账户” | Rillora、Apple和在线服务登录用“账号”；不机械改写用户自己填写的账户文字 |
| Name / Directions / Details | 名称 / 查找指引 / 详细资料 | 名称档含名称与类别；查找指引含服务方、位置、处理意愿，不含备注或识别提示；详细资料含获准的已保存详细字段 |
| Preferred outcome / Wishes | 处理意愿 | “申请转移／关闭／删除”，不写成Rillora已执行该动作 |
| Masked reference / hint | 识别提示（如尾号） | 避免“脱敏提示”让人误以为系统会自动遮盖输入；勿填密码、私钥或助记词 |
| Shared reviews | 共同复核 | 复核收件箱、复核记录、复核频率；普通网络检查仍用“检查” |
| Account inheritance | 账号身后处理指南 | 与指南实际范围一致，不暗示Rillora授予继承、账号访问或法律代表资格 |
| Start Here guide | 导出指引副本；预览与导出指引 | 与“快速入门”区分，清楚表明制作独立副本的用途 |
| Complete map backup | 完整备份 | 与最小指引、加密包分开；明确持有明文文件即可读取 |
| Included place | 免费共享名额 / 当前免费共享接收人 | 对应现有Free一人持续共享，不改变额度或Family权益 |
| Free / Family | 免费版 / 家庭版 | 仅显示翻译；planCode、美元价格、Apple商品名称和法律原文不改 |
| Recovery key / deletion reference | 恢复密钥 / 删除查询凭据 | 二者不是同一种文件，不可互换；不放入用户聊天或普通日志 |

## 有代表性的修订

| 原中文 | 当前中文 | 原因 |
| --- | --- | --- |
