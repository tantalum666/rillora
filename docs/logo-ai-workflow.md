## Scope Boundary — LOCKED

本合同只在任务直接涉及 **Rillora Logo** 时生效，包括：Logo概念、图形标、字标配对、AI生成变体、矢量重建、正反白与小尺寸测试、Logo相似性预清查，以及Logo通过后的配色与应用。

它不是整个项目的通用要求，也不约束：

- 产品功能、MVP、市场验证或商业判断；
- Web与iOS的信息架构、界面、组件、插画或动效；
- 后端、安全、身份、数据区域或部署；
- 品牌命名、中文名、标语、域名或法律策略；
- Logo之外的普通视觉资产生产方式。

不得因为本合同使用了阶段门，就推导出整个项目必须采用同样的AI工具、审批节奏或设计方法。上述事项继续由`docs/product.md`的Authority Map路由。

## Locked Decision

Rillora Logo采用混合生产方法：

`品牌策略 -> 纯文字概念命题 -> 自有结构骨架 -> 草图约束／原生矢量AI变体 -> 人工矢量重建 -> 光学与相似性门 -> 配色与身份应用`

AI只能作为概念发散与受控矢量变体工具，不能把一次提示生成的栅格图直接当作最终Logo母版。最终Logo必须有人类做出的结构选择、路径重建、字形判断、光学校正与相似性判断。

本决定取代此前“等待Owner决定”的拟议状态，也关闭继续用通用栅格模型直接生成成品感Logo的路线。它没有选定任何Logo，也没有恢复产品开发。

## Closed Routes — LOCKED

- 此前展示并被否决的所有Logo图形只保留为历史证据，不得精修、描摹、组合、局部复用或改名复活。
- 单独`R`及隐藏`R`的字母图形路线继续关闭；非字母图形标类别仍然开放。
- 不把Apple、Mastercard、Chase、Polestar或其他真实商标图像作为生成模型的结构参考。
- 不使用“in the style of”或等价方式模仿任何现有品牌。
- 不再把长篇否定词列表、多个真实商标参考和“终稿”要求压进一次生成。
- 不把自动描摹路径、AI导出的原始SVG或单张栅格图称为生产Logo。

Apple、Mastercard、Chase和Polestar只保留为文字化审美坐标：紧凑独立轮廓、精确有限构造、结构性负空间、一处可记忆变化、黑白成立和克制张力。不得复制水果、重叠圆、旋转楔形、四角星或其他受保护形态。

## Mandatory Gates

每一门都必须先完成并获得Owner明确通过，才可进入下一门。`通过`只锁定当前门，不自动批准后续门或最终Logo。

### Gate 0 — Text-only concept propositions

首轮必须正好提交三份纯文字概念命题，不生成Logo图片。每份必须说明：

1. 一个与Rillora有关的核心动作；
2. 一个需要同时容纳的情感张力；
3. 为什么该命题不是任意SaaS、金融、安全或法律品牌都能使用；
4. 最可能产生的品类误读和应主动排除的俗套。

Owner可以选择、修改或全部否决。没有通过的命题不得进入绘制。

### Gate 1 — Proprietary structural skeletons

只为通过的命题制作少量自有极简骨架。骨架只定义质量、接点、开口、正负空间和比例，不加入颜色、Mockup、装饰或真实商标参考，也不伪装成完成Logo。

Owner必须先判断构造逻辑与品类读感。没有通过的骨架不得进入AI变体。

### Gate 2 — Controlled AI vector variation

- 优先使用Adobe Illustrator Concept to Vector或Recraft原生Vector；工具可替换，但“骨架约束、可编辑矢量、单变量比较”的要求不可替换。
- 提示保持短、正向、具体，通常为`1–3`句；说明用途、概念、结构关系、纯黑白输出和本轮唯一变量。
- 固定同一骨架，每次只改变一个变量；同一轮的结果必须可直接比较。
- 每个通过骨架可生成`6–12`个受控变体，不从不同随机构图中挑一张“碰运气”。
- ChatGPT Images或Midjourney只可用于前期发散证据，不作为最终路径来源。

任何AI输出在本门都只是生成变体，不是生产母版。

### Gate 3 — Manual vector reconstruction

入选方向必须在Illustrator或Figma中人工重建，不直接交付自动描摹或原始生成路径。至少检查并处理：

- 多余锚点、自交、重叠路径和开放端点；
- 偶然切线、不受控曲率和机械等距造成的光学失衡；
- 反白后需要独立修正的间隙、端点和重量；
- 与`Rillora`字标配对时的比例、间距和基线；
- `Rillora`准确拼写，尤其避免`ll`造成`Rilora`误读。

### Gate 4 — Optical QA

每个生产候选必须至少通过：

- 纯黑正稿与纯白反稿；
- `64 / 32 / 24 / 16px`真实像素测试；
- 模糊／眯眼轮廓测试；
- App图标遮罩与favicon测试；
- 横向组合标志和正式文件场景；
- 必要时独立绘制正稿与反白母版，而不是数学复制。

如果关键负形坍塌、轮廓必须依赖颜色或解释才能成立，候选退回前一门。

### Gate 5 — Ownership and similarity

配色前必须进行：

- 品类误读检查；
- 无提示回忆检查；
- USPTO、EUIPO、WIPO和目标法域的公开相似性预清查；
- 进入正式使用前，由目标市场专业人士完成所需的法律清查。

公开数据库检索只能称为产品级预清查，不能称为商标法律通过、可注册或不侵权意见。

### Gate 6 — Colour and identity application

只有黑白形状获得Owner批准并通过相似性门后，才开发颜色、最终字标关系、App图标、Web/iOS品牌应用和正式文件系统。颜色不得用于掩盖轮廓或负空间问题。

本门完成仍不自动代表商标注册、产品发布或开发恢复。

## Prompt Contract

允许的提示结构：

1. 用途：为Rillora设计非字母图形标的受控变体；
2. 概念：本轮已通过的唯一概念命题；
3. 结构：固定骨架中各质量与负空间的关系；
4. 输出：平面、纯黑白、无字、无Mockup、可编辑矢量；
5. 变量：本次唯一允许改变的比例、开口、接点或曲率。

禁止：

- 只写`premium / minimal / elegant`等空泛风格词；
- 同时改变多个结构变量；
- 附加多个真实品牌图像让模型“综合”；
- 以长篇`Avoid`列表替代清晰的正向结构描述；
- 要求生成器一次完成概念、终稿、字标、配色与应用板。

## Exact Next Gate

Owner已否决Gate 2短名单`A4 / C2 / C4`：三者只是同一圆形＋S形接缝拓扑的参数微调，信息增量低、过于单调，并引发合理的相似商标拥挤担忧。该判断关闭全部12枚变体和`Dual Embrace`的具体视觉骨架；`The Next Reader / 后来者可读`概念命题仍有效。随后一次自动角形发散稿也因通用科技构件感和低光学质量被关闭，未进入候选资产。下一门先重置形态生成方法：形态与光学质量先于产品隐喻，内部草图必须通过无文字轮廓、曲率、负空间、小尺寸和品类误读阈值才可提交；不得再把产品关系图、参数化变体差异或AI初稿误当成品牌候选。核心混合流程、人工重建和证据边界仍然有效；这次失败不把Logo合同扩张到其他项目工作。

本门的活动执行规范是`docs/logo-form-brief.md`。它定义五个拓扑不同的内部形态家族、硬失败条件、`84/100`无文案盲审阈值和Owner提交包。该文件不锁定任何图形，也不取代本合同；它只防止未成熟草图再次越级展示。

首轮已按五个形态家族各进行最多两次隔离生成，结果为零幸存者；最佳诊断分仍只有`74/100`，所有方向都触发至少一项硬失败。没有失败图被复制进项目候选目录。继续改写栅格提示词的路线因此暂停；下一步需要设计师主导的手工草图、选择与矢量构形。该结果不否决AI在后续受控变体中的辅助角色，但AI不再负责产生下一枚Owner-facing起始形态。

随后一次经Owner授权的Figma Agent有界实验分别测试F1实心轮廓与F2设计反形。Agent可以生成可编辑矢量和布尔路径，但三次执行仍收敛为圆圈X／铅笔／宝石线框、咬口软团块／聊天气泡，以及矩形孔团块／相机App图标／眼睛甜甜圈等熟悉语法，零结果通过硬失败门。该证据进一步关闭“让无草图约束的Figma Agent发明下一枚起始形态”，不关闭Figma作为Gate 3人工重建环境，也不关闭在设计师选定骨架后使用AI做受控单变量矢量辅助。
