# Rillora：200—500美元获客预算与止损方案

Status: PLANNING SCENARIOS / NOT A SPEND AUTHORIZATION / NO AD CAMPAIGN CREATED
Last updated: 2026-10-19 (Asia/Shanghai)

Owner希望研究平台并让200—500美元尽量产生实际价值。本方案按一次首轮验证的新增营销现金上限理解这两个金额，不解释为每月预算、必须花完的额度或已经授权充值。现有云服务／域名等运营成本另记，新增营销认证费、工具费、税费及汇兑仍应包含在本上限内。没有购买、优惠充值、投放或新增跟踪SDK。

## 当前结论

200—500美元可以用于小规模验证，不能保证买到稳定数量的付费用户，更不能保证每一次点击都不浪费。具体X帖子未提供，本轮没有核实其分母、地域、产品价格、已有粉丝、返广告金、退款或工时，因此不把别人的“200—500获客”当Rillora的成本基准。

本轮建议：先用已有官网、邮箱、Logo／横幅和真实演示做自然触达；归因和用户任务路径可核对后，第一笔只测试50美元的一个渠道。后续资金依证据分批释放。没有证据时把钱留住也是合格结果。

## 小预算的算术

用于理解成本的近似式：媒体CAC＝每次点击成本÷点击到新净付费家庭的转化率。

| 假设每次点击成本 | 假设净付费转化率 | 对应媒体CAC |
| ---: | ---: | ---: |
| 0.50美元 | 2% | 25美元 |
| 1.00美元 | 2% | 50美元 |
| 2.00美元 | 2% | 100美元 |
| 1.00美元 | 4% | 25美元 |

这些只是算术情景，**不是Rillora／Google／X的实际CPC或预测**。例如花200美元、CPC1美元、转化2%，期望值约4个付费家庭；真实结果可能为0。即使得到4个，CAC仍为50美元，不能因为首年Web标价88.99就认定盈利。

50美元、CPC1美元、独立点击转化概率2%的简化例子，50次点击中零付款概率约36.4%。因此小样本的零付款不是市场被证明失败；同样，一笔朋友付款也不证明可规模化。预算止损是控制风险，不是统计显著性结论。[复算记录](../../collaboration/verification/marketing-platforms-20261019/calculations.json)。

扩量前只看第一年：首年预计贡献＝预计净收款－支付／平台费用－退款拒付准备－增量服务与直接支持成本。使用真实费率与保守服务成本输入，未知不能当0；不要先乘三年LTV。贡献必须为正，才使用Agent提出的保守观察上限：允许现金CAC＝min(25美元，首年预计贡献的40%)；贡献非正或关键输入未知时不扩量。这是拟议管理线，不是市场标准或已确认利润；若贡献为60美元则上限24美元，若为40美元则为16美元。固定运营成本、研发和获客劳动仍需另覆盖。旧49／68／88.80模型不直接作为当前利润证明。

## 预算怎么分

| 用途 | 总上限200美元 | 总上限500美元 | 释放条件 |
| --- | ---: | ---: | --- |
| 复用内容、基础资料页、已有工具 | 0 | 0 | 本人工时另记；不买新套餐 |
| A：首个单渠道实验 | 50 | 50 | 下方投放前置项完成且具体执行获授权 |
| B：一次有依据的修正／复核 | 50 | 100 | A带来真实激活／共享信号，并明确能回答的问题；每笔仍不超过50 |
| C：只给已有付款证据的方向追加 | 50 | 250 | 至少两批可比较结果，累计至少5个外部净付费家庭，CAC在观察线上且首年贡献估算为正；分50一笔，不一次加满 |
| 费用缓冲及未承诺资金 | 50 | 100 | 支付实际广告税费／汇兑或经另行决定的必要费用；没有用途就不花 |
| **总现金上限** | **200** | **500** | 含新增营销现金，不自动耗尽 |

所以两种情景的媒体费用最大分别150／400美元；A结束不合格时可以只花50美元或更少。缓冲不能当“亏了继续追”的资金。若开户／订阅固定费用占用缓冲，先减少媒体预算，不能加到总额之外。500方案不是要求同时开更多平台。

## 第一次50美元优先测试什么

**建议候选为Google Search的高意图小词组**，原因是查询本身可表达在找数字遗产整理工具，而不是先教育一大片无意购买的人。这是待验证的渠道假设，不是保证Google最便宜。

1. 一个服务市场、一个语言：先以已开放市场中的US-English为候选。实际开户身份和服务市场必须真实；地区选Presence，不将“对美国感兴趣”当身在美国。地域判断仍非100%准确。[官方地区说明](https://support.google.com/google-ads/answer/9376662?hl=en)。
2. 核对词量和可接受出价。种子词：digital legacy planner、digital legacy organizer、digital legacy app。Keyword Planner的预测需要完成账户／账单设置，本轮没有进入或填卡，因此没有取得真实量价预测；不要假称这一步已经做完。[官方预测条件](https://support.google.com/google-ads/answer/3022575?hl=en)。
3. 在实际界面允许时仅选Search、短名单精确／词组匹配与手动CPC或带出价上限的Max clicks；不默认启用广泛扩展、PMax、展示网络、搜索合作伙伴、品牌词抢自然流量或多国家。精确匹配也可能匹配同义近似查询，必须读实际搜索词。
4. 排除明显不提供的意图，例如will template、probate lawyer、inheritance tax calculator、obituary及求职／游戏等误匹配；不要把含free的所有搜索一刀切排除，因为产品确有Free入口。不要用律师、遗嘱生成或自动资产转移的广告承诺吸引错的人。
5. 广告落到与意图一致的/en/product或具体清单页，明确整理／共享的用途，通向现有正式Web。首轮不同时改价、换受众、换落地页和换创意；优先只改一个变量。
6. 本次官方文档已确认新Search campaign可使用Campaign total budget。若实际账户提供此选项，设置总媒体上限50美元、7日起止；它限制全期而非每天均匀花费。若界面没有该能力，保持暂停，先制定等价可核对上限，不把平均日预算错当总预算。[总预算规则](https://support.google.com/google-ads/answer/10486938?hl=en)。

流量太少时，先记录词量限制；不要为花完钱扩大成“遗嘱”“保险”“投资”等泛词。Google不合适时，下一笔可换成**已经由自然内容带来合格访问**的Meta或X候选，但必须沿用同一总额和指标，不能三家同时各花50后只比较点击价。

## 投放前必须能回答的四件事

1. 付费点击落在哪个页面，实际可用市场和语言是否一致，当前HTTPSwww入口正常。
2. 本批来源能否跟到真实开始整理、共享和付款。现有UTM只是链接命名；当前事件合同不是现成的跨域付款归因报表。
3. 一次审核过的来源代码能否保持到认证后并在自有系统做最少记录，拒绝可选跟踪时如何处理；只保留低敏感campaign code，不上传私人事项／邮箱到广告平台。新增字段与同意／保存边界需单独实现核验，**本轮未实现**。初期用用户自愿说明来源可辅助，但不能据此伪造精确归因。
4. 广告上限、截止时间、账单币种、税费／汇兑和付款方式是否读回；核验使用广告预览与既有合成路径，不自己点击收费广告或制造真钱测试。

先有5名非Owner／审核／合成用户完成核心整理，其中至少2组接收人找到获准资料，是Agent建议的首轮小额验证前置。它低于整个MVP的市场验证目标，不能据此宣称产品市场匹配。达不到时优先修文案或使用阻塞，不买更多流量。

## 明确的停止与继续条件

| 观察 | 动作 | 解释边界 |
| --- | --- | --- |
| 链接／认证／来源记录坏、地区不符或实际计费超出预期 | 立即暂停，先修可复现问题 | 不用更多流量验证坏链路 |
| 可见查询抽样20次以上，其中明显不相关超过20% | 暂停调整匹配／否定词／落地页 | 这是操作阈值，不是统计结论；平台可能不展示全部查询 |
| A达到50美元上限，或达到约30次可确认合格落地访问但无人开始整理 | 暂停购买流量，排查诉求／页面／信任／操作 | 不强行把花费或访问凑满；缺少可靠访问统计时不得拿广告点击冒充 |
| 有实际整理和共享、尚无付款 | 用自愿反馈判断免费权益已满足还是付费价值不清；B只允许一次明确修正 | 年付决策可能滞后，按7／14日分别看；不得自动降价或赠品换好评 |
| 累计再花完B仍无外部净付款，或可计算CAC超过允许上限 | 停止该付费方向，保留未花资金 | 不靠“还在学习期”无限续费，也不声称证明整个产品无需求 |
| C条件满足 | 每次最多再投50，并看退款／取消／工时 | 5笔也只够继续小额试验，不足证明稳定CAC；不自动扩至500全额 |

每笔实验先写问题、预计能观察的行为、预算与停止条件；结束后记录一个结论。原有[全MVP方向信号](../mvp.md)及30／90天维护观察继续保持，不能用广告的小样本门替代。

## 这批钱先不花在哪里

- 买粉、刷收藏、互赞群、榜单／评论、Product Hunt付费Hunter和未经真实受众核验的KOL整包。
- 为凑全平台购买认证／Premium／代运营／社媒排程套餐；已有邮箱和素材足够准备第一轮。
- TikTok、LinkedIn、YouTube视频展示等多渠道同时投；不在App仍待审时买Apple Ads安装。
- Facebook／Instagram的iOS应用内Boost付款。官方说明网页Ads Manager／Business Suite等路径可避免Apple服务费，先用网页管理并核对账单。[官方说明](https://www.facebook.com/business/help/704141224249342)。
- 为得到“花500送500”广告金而超出原计划；赠送额度有资格、有效期和适用范围，不等于退现金。
- 在归因不清时新增付费MMP、CRM或分析订阅。先完成最小可用的自有核对，不把广告平台归因收入当真实净利润。

## 首次获客执行记录（Sales首单路线）

- **对象／机会：**Rillora首批外部家庭用户；没有现成CRM机会、阶段、成交日期或客户承诺。本项目文件和本轮官方来源足以制定首轮方案，不为填表购买CRM。
- **决策角色：**假设规划者为选择／付费者，接收人为价值验证参与者；尚无具名客户或支持／反对态度证据。Owner负责预算和真实账号，Agent负责素材／归因方案／记录，不代用户做法律或个人资料决定。
- **主要风险：**需求／价值尚未实证、付费来源归因不足、敏感兴趣／平台资格、预算误配置、年费收入被当作利润。对应控制分别是小批任务、来源核对、官方规则＋实际账户验收、全期上限、首年贡献计算。
- **下一步顺序：**①准备真实品牌资料及一条用途明确的演示；②选两处允许的自然渠道；③完成5名规划者／2组接收人任务；④补最小来源和净付款核对；⑤检查单市场词量及资格；⑥仅在具体执行获授权后开A；⑦按结果决定B／C或停止。Owner／Agent为建议责任人，时间从实际启动算，不填虚构固定成交日期。
- **证据缺口：**真实CPC、词量、各广告账号资格、激活／付款率、退款、直接服务成本和长期留存均未测。没有把平台官方推荐预算或网上成功案例当成Rillora预测。最小下一项是来源→任务→付款的可核对链路及首批自愿任务，而不是新增功能清单。
