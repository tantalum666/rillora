## 新增／复现发现

### INT-01 / P2 / 已复现交互问题：关闭编辑抽屉后丢失触发点焦点

步骤：事项列表中对文档行按 Enter → 打开 Edit matter → Escape → 再按 Tab。
预期：回到触发事项行；下一次 Tab 继续后续同级控件。
实际：关闭后 AX 焦点是页面根；下一次 Tab 到页面顶部 Appearance。重复测试一致，截图 52–53。
修复建议：打开时保留触发器引用，关闭/路由返回时恢复焦点；回归鼠标关闭、Escape、浏览器返回、长列表滚动位置。不能据此宣称键盘完全不可用或 WCAG 整体不合格。

### UI-01 / P2 / 已复现呈现问题：窄屏隐藏事项状态文字，只剩颜色圆点

桌面列表显示 Draft（44），500/400 CSS 窄屏只见浅色圆点（45–46、50）。AX 仍有状态文本，但视觉用户看不到含义。
建议：保留短状态文字或紧凑标签；不要把状态只编码成色点。受影响是窄视口 Web，不是已验证的原生 App。

### UI-02 / P2 / 已复现呈现问题：活动记录的日期时间被挤为竖向碎行

Activity 中 Matter added / archived 行把时间排为 Oct / 4, / 2026, / 12:05 / PM。400 CSS 屏幕与恢复 1181 CSS 桌面均复现（59、61）；带长标题的行更严重，部分无目标条目的事件却能正常一行显示。
建议：动作、目标和时间分成稳定布局；时间独占一行或固定不换行宽度，标题允许在自己的列换行。回归长中文/英文标题与窄屏。

### OBS-01 / P2 / 待产品确认：活动记录未见恢复事件

已完成 archive→Restore privately，随后新增文档。Activity 及刷新后能看到归档、之后新增文档，却未观察到恢复事件（59、61，操作结果 44）。这不是已证明的后端日志丢失；需核对事件范围、延迟及产品是否承诺记录恢复。
建议：若“Private audit / Plan activity”用于帮助用户追溯状态，恢复应有对应事件，说明恢复为私密 Draft，避免历史最后停在 archived。

### UX-09 / P2：Start Here guide 的入口容易被当成新手教程

My plan 的辅助按钮“Review Start Here guide”进入后第一问是“Who is this copy for?”，再到 Review / Format / Save（34–38）。它是生成可携带说明副本的流程，不解释那 5 项 essentials。
建议：入口写“Preview or export your directions guide”，另提供真正的新手任务清单。与 UX-01 合并排期更有效。

### UX-10 / P3：审阅设置弹窗不解释禁用前提

底层页说当前 plan 不支持，但点 Review schedule & collaborator 后弹窗字段/Save 禁用，只显示 Every 3 months、No one、Pause reviews and suggestions，缺失当前计划限制说明（55–56）。
建议：在弹窗内就地解释不可用原因；没有计划时不显示会让人误以为已开启的暂停动作。
